lab2-http

Лабораторная работа №2 — исследование HTTP-запросов и ответов.

Содержимое

- "report.md" — отчёт по заданиям A–F.
- "commands.log" — журнал выполненных команд и результатов.
- "screenshots/" — скриншоты терминала и DevTools.

Перед сдачей

1. Указать имя и дату в "report.md".
2. Добавить не менее шести скриншотов в "screenshots/".
3. Проверить ответы и заполнить таблицу DevTools по фактическим данным.
4. Сделать не менее трёх осмысленных коммитов и выполнить "git push".
